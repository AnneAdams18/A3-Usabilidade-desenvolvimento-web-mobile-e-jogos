# 📦 Sistema de Controle de Estoque - A3 UNISUL

Projeto desenvolvido para a Unidade Curricular **Usabilidade e Desenvolvimento WEB** da UNISUL.
Objetivo: criar um sistema web para controle de estoque, aplicando princípios de **usabilidade, acessibilidade e inclusão**.

## 🚀 Funcionalidades
- CRUD de **Produtos** e **Categorias**
- Registro de **Movimentações** (Entrada/Saída)
- Relatórios:
  - Lista de preços
  - Balanço físico/financeiro
  - Produtos abaixo do mínimo
  - Quantidade por categoria
  - Produto com maior entrada/saída

## 🛠️ Tecnologias
- Java Servlet & JSP  
- HTML, CSS, JavaScript  
- MySQL  

## 📂 Estrutura
src/ -> Código fonte (Java, Servlets, JSP) 
web/ -> HTML, CSS, JS 
db/ -> Scripts SQL 
docs/ -> Documentação

## ▶️ Execução
1. Configurar banco MySQL com script em `db/`.
2. Importar projeto na IDE (Eclipse/IntelliJ).
3. Executar no servidor Tomcat.
4. Acessar em: `http://localhost:8080/estoque`
